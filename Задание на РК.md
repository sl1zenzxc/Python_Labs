# РК 1. Загрузка и EDA-анализ данных об SQL-инъекциях через защищенный HTTP-клиент

## Цель работы

Научиться:
  1. Работать с закрытым контуром и авторизовываться на сервере по HTTP.
  2. Использовать Pydantic для валидации и типизации данных, получаемых по HTTP.
  3. Загружать данные из REST API и объединять их в единый pandas.DataFrame.
  4. Проводить разведочный анализ данных (EDA) на реальном наборе данных об атаках SQL-инъекций.

## Исходные данные

На сервере в закрытом контуре развернут REST API, предоставляющий доступ к базе знаний об SQL-инъекциях. Данные распределены по 5 группам (эндпоинтам), каждая содержит от 14 тыс. строки.

| № | Эндпоинт | Столбцов | Поля |
|---|---|---|---|
| 1 | /api/identification | 4 | id, Title, Category, Attack Type |
| 2 | /api/attack_description | 3 | id, Scenario Description, Attack Steps, Tools Used |
| 3 | /api/target_vulnerability | 3 | id, Target Type, Vulnerability, MITRE Technique |
| 4 | /api/impact_protection | 3 | id, Impact, Detection Method, Solution |
| 5 | /api/metadata | 2 | id, Tags, Source |

Важно: поля содержат пустые значения (null) в текстовых полях.

## Доступ к серверу

  - Адрес: http://<server-ip>:<port> (выдается преподавателем)
  - Аутентификация: Basic Auth
  - Тестовые учетные данные:
    - Логин: student
    - Пароль: student_pass

## Часть 1. HTTP-клиент с Pydantic-моделями

### Требования к реализации

Создайте файл client.py, который:

1. Авторизуется на сервере по Basic Auth.
2. Выполняет GET-запросы к 5 эндпоинтам.
3. Валидирует ответы через Pydantic-модели (BaseModel).
4. Обрабатывает ошибки: TimeoutException, RequestError, статусы 401/403/404/5xx.
5. Объединяет все 5 групп в один DataFrame по ключу id.
6. Сохраняет результат в sql_injections_merged.csv.

### Pydantic-модели

Для каждой группы создайте отдельную модель. Обратите внимание:

- Алиасы полей (реальные имена в JSON содержат пробелы, а Python-атрибуты — snake_case).
- model_config = ConfigDict(populate_by_name=True) — позволяет создавать модель и по алиасу, и по имени поля.
- Все текстовые поля — Optional[str] = Field(default=None, alias="...").

Пример (только для одной группы, остальные — аналогично):

```
from pydantic import BaseModel, ConfigDict, Field

class IdentificationRow(BaseModel):
    model_config = ConfigDict(populate_by_name=True)

    id: int
    title: Optional[str] = Field(default=None, alias="Title")
    category: Optional[str] = Field(default=None, alias="Category")
    attack_type: Optional[str] = Field(default=None, alias="Attack Type")
```

### Структура APIClient

Реализуйте класс APIClient с использованием httpx.Client:

  - Конструктор принимает base_url, login, password, timeout.
  - Поддерживает контекстный менеджер (__enter__ / __exit__).
  - Внутренний метод _get_json(path) -> List[Dict] выполняет запрос и обрабатывает ошибки (401, 403, 404, 5xx, таймауты).
  - Пять методов fetch_* возвращают List[<PydanticModel>] (валидация через model_validate).
  - Метод fetch_all() объединяет все группы в один DataFrame через pd.merge(..., on="id", how="inner").

## Часть 2. EDA-анализ

Требования к реализации

Создайте файл eda.ipynb

| № | Категория анализа | Что сделать | Что вывести | Обязательный вывод |
|---|-------------------|-------------|-------------|---------------------|
| 1 | Общая информация | Размер, типы, пропуски, дубликаты | Таблица пропусков + bar chart пропусков | Есть ли пропуски? Где больше всего? Есть ли дубликаты? |
| 2 | Category | value_counts, доли | Топ-10 + bar chart + pie chart (топ-8 + прочие) | Какие категории доминируют? Насколько равномерно распределение? |
| 3 | Attack Type | value_counts | Топ-10 + bar chart | Какие типы атак встречаются чаще всего? Высокая ли уникальность? |
| 4 | Tools Used | re.split(r"[,;#]"), Counter | Топ-15 + bar chart | Какие инструменты самые популярные? Что это говорит о типичном стеке атакующего? |
| 5 | MITRE Technique | re.findall(r"T\d{4}(?:\.\d{3})?"), Counter | Топ-10 + bar chart | Какие техники доминируют? Соответствуют ли они типу атак? |
| 6 | Tags | re.split(r"[,;#]"), lower, Counter | Топ-20 + bar chart | Какие теги самые частые? О чем это говорит (redteam, phishing, mitm)? |
| 7 | Source | re.split(r"[,;]"), Counter | Топ-15 + bar chart | Какие источники наиболее авторитетны? |
| 8 | Category x Attack Type | pd.crosstab, топ-10 x топ-10 | 2 heatmap: абсолютные и доли по строке | Есть ли выраженные пары «категория -> тип атаки»? |
| 9 | Attack Type x MITRE | Создать mitre_main (первая техника), crosstab, топ-8 x топ-10 | Heatmap | Какие MITRE-техники привязаны к каким типам атак? |
| 10 | Длины текстов | len_scenario_description, len_attack_steps, len_solution | describe().round(1) + 3 гистограммы с KDE | Какое поле самое длинное? Есть ли выбросы? |
| 11 | Частые слова в Solution | Токенизация [A-Za-z][A-Za-z\-]+, фильтр стоп-слов, Counter | Топ-20 + bar chart | Какие рекомендации по защите встречаются чаще всего? |
| 12 | Финальная сводка | Уникальные значения по всем полям | Таблица с метриками | — |
  
**Важно!** После каждого пункта необходимо написать 1–3 предложения: что показал анализ, какие значения ключевые, какие аномалии или закономерности.

| 1 | Какие категории и типы атак доминируют в датасете |
